# Code Templates — Domain, Data & Presentation Layers

> **Purpose:** Copy-paste templates for every layer. All code generation MUST follow these patterns.

---

## ⚠️ Data → Domain layer: single source of truth

**Response models, entities, remote datasources and repository implementations are defined ONLY in
[`.claude/skills/clean_architecture_pattern.md`](../skills/clean_architecture_pattern.md). Read it before writing any of them.**

Summary of that pattern (do not deviate):

| Layer | File | Rule |
|-------|------|------|
| Data | `data/models/*_response.dart` | Wire-shape DTO, **all fields nullable**, decoded with `SafeJson.as*`, `json.autoSafe.raw` at top level only |
| Domain | `domain/entities/*_entity.dart` | **Non-nullable fields with defaults**, `const` constructor, extends `Equatable`, no `fromJson` |
| Data | `data/repositories/*_repository_impl.dart` | `handleException()` + explicit field-by-field model → entity mapping with `??` defaults |

- ❌ Models **never** `extend` entities.
- ❌ No `.toEntity()` helpers on models — mapping lives in the repository impl.
- ❌ No raw casts (`json['x'] as String`) — always `SafeJson.as*()`.

## Domain Layer Templates

### Repository Contract Template

```dart
// lib/features/{feature}/domain/repositories/{feature}_repository.dart
import 'package:dartz/dartz.dart';
import '../../../../core/error/failures.dart';
import '../entities/{entity_name}_entity.dart';

abstract class {Feature}Repository {
  Future<Either<Failure, {Entity}Entity>> get{Entity}(String id);
  Future<Either<Failure, List<{Entity}Entity>>> get{Entity}List();
}
```

- Returns `Either<Failure, Entity>` — **never** the response model.

### UseCase Template

```dart
// lib/features/{feature}/domain/usecases/{action}_usecase.dart
import 'package:dartz/dartz.dart';
import 'package:equatable/equatable.dart';
import '../../../../core/error/failures.dart';
import '../../../../core/usecases/usecase.dart';
import '../entities/{entity_name}_entity.dart';
import '../repositories/{feature}_repository.dart';

class {Action}UseCase implements UseCase<{Return}Entity, {Action}Params> {
  final {Feature}Repository repository;

  {Action}UseCase({required this.repository});

  @override
  Future<Either<Failure, {Return}Entity>> call({Action}Params params) {
    return repository.{action}(params.id);
  }
}

class {Action}Params extends Equatable {
  final String id;

  const {Action}Params({required this.id});

  @override
  List<Object?> get props => [id];
}
```

- Every UseCase needs a mirrored test: `test/features/{feature}/domain/usecases/{action}_usecase_test.dart`.

## Presentation Layer Templates

State, Notifier / Bloc, Page and their tests depend on the project's state management and live in
**`.claude/rules/STATE_MANAGEMENT.md`** (Riverpod or flutter_bloc — installed to match what `ssl_cli` generated).

Rules for every state management:
- ✅ Global widgets only — `GlobalAppBar`, `GlobalText`, `GlobalButton`, `GlobalLoader`, … (never `AppBar`, `Text`, `ElevatedButton`, `CircularProgressIndicator`)
- ✅ ScreenUtil (`.w`, `.h`, `.r`) for sizes — `GlobalText` handles `.sp` internally
- ✅ UseCases resolved via `sl<...>()` and `Either` folded into state — no business logic in widgets

## Common Code Mistakes

**Data → Domain** (full list in `clean_architecture_pattern.md` → Anti-patterns):
- ❌ `class FooModel extends FooEntity` — keep models and entities separate
- ❌ Nullable fields in entities — use defaults
- ❌ Raw `as` casting: `json['id'] as String`
- ❌ Adding `json.autoSafe.raw` to nested models (top-level only)
- ❌ Forgetting to run `autosafe /path/to/{name}_response.dart` after modifying `fromJson`

**UI:**
- ❌ `AppBar(...)` → ✅ `GlobalAppBar(title: ...)`
- ❌ Raw Flutter widgets, hardcoded colors, raw asset paths

**Security:**
- ❌ Hardcoding API keys, tokens, or passwords in any Dart file
- ❌ Committing `google-services.json` or `GoogleService-Info.plist`
- ❌ Using `flutter_dotenv` or `String.fromEnvironment` for secrets — use envied only
- ❌ Editing `key.properties` or `Secret.xcconfig` manually — auto-generated by script
- ❌ `print()` / logging of PII (NID, phone, account numbers) or tokens
